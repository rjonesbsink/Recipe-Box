# Recipe Box

A recipe keeper for your phone. No account, no sign-in — recipes are saved only on your own device and it works offline.

**Open it:** https://rjonesbsink.github.io/Recipe-Box/

## Install
1. Open the link in Safari (iPhone) or Chrome (Android), while online.
2. iPhone: Share → **Add to Home Screen**. Android: ⋮ → **Install app**.
3. Open it once from the home-screen icon while still online. After that it works with no signal.

## What it does
- Save recipes with photos, tags, ratings and notes; search and sort them.
- **Paste a whole recipe** from a website or text and it fills in the fields.
- **Serving scaler** — change servings and ingredient amounts adjust.
- **Cook mode** — big step-by-step view that keeps the screen on.
- **Step timers** — tap any time in a step (⏱ 45 minutes) to start a countdown.
- **Shopping list** — add recipes and matching ingredients are combined.
- **Share** a single recipe as a file (for other Recipe Box users) or as text.
- **Print** a clean copy of any recipe.
- **Backups** — ⋯ → Save backup file. If the phone is lost, recipes go with it unless you have a backup.
