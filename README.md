# Recipe Box

A simple recipe keeper for your phone. No account, no sign-in — recipes are saved only on your own device and it works offline.

**Open it:** https://rjonesbsink.github.io/Recipe-Box/

1. Open the link in Safari (iPhone) or Chrome (Android).
2. iPhone: Share → **Add to Home Screen**. Android: ⋮ → **Install app**.
3. Use the ⋯ button to save a backup file now and then — if the phone is lost, recipes go with it.
